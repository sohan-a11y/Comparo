Comparo: AI-powered legal & contract clause comparison engine with semantic diff highlighting.

---

## 🌟 Key Features

- ⚖️ **Semantic Clause Alignment**: Matches clauses across contracts even when wording differs completely.
- 🔍 **Risk & Ambiguity Detection**: Highlights high-risk indemnity, liability, and termination clauses.
- 🎨 **Interactive Visual Diff**: Streamlit dashboard presenting color-coded clause comparisons.
- 📄 **PDF & DOCX Support**: Extracts clean text from legal documents seamlessly.

## 🚀 Quick Start

### Prerequisites
- Python 3.9+ / Node.js (depending on module)
- Git

### Installation
```bash
# Clone repository
git clone https://github.com/sohan-a11y/Comparo.git
cd Comparo

# Install dependencies (if python project)
pip install -r requirements.txt
```
